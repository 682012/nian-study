# V9：书案界面与功能修复

版本：9.0.0，2026-09-06。基于原 main 的 61b19b0 开发。

## 页面

- 统一纸色、墨绿、边框、字体层级与按钮。首页突出念安和今日课业。
- 四个导航页：今日书案、三科练习、藏书楼、逛逛书院；手机保留练习、对话、错题与学录快捷入口。
- 保留原有练习、知识图谱、诗笺、地图、学录导入导出及 Android 下载，缩短首页并消除重复悬浮入口。
- 增加学科筛选、键盘焦点、弹窗焦点限制与背景禁用、减少动态效果偏好及手机安全区适配。

## 修复

- 每次作答同步原 React 学识状态，退出闯关不再刷新整页。
- 后备词库使用原词 ID；直接共享完整 822 词，避免重复下载核心脚本。
- 每日 20 题按当天保存，避免作答改变权重后重新打开变成另一张卷。
- 阅读解析保留采分点；错题事件携带题干、知识点和解释，供念安讲解。
- 随机概率、坐标中点、方程组选项避免重复；修正增长率浮点尾数和对数底数排版。
- 换题回到题干，答后显示解析，练习关闭按钮保持可见；百连挑战结算数量修正。
- 防止重复发送对话，修正输入上限与设置字段；新用户不再直接判为英语薄弱。
- 取消旧的全局原生语音替换脚本，中文、英文、云端朗读由同一控制器管理。
- 等待系统音色，处理无音色和播放超时；停止时取消请求、播放和对象 URL，防止晚到音频继续播放。
- 云端模型、音色、英文音色和端点设置正确接线；移除默认 HTTP 语音桥，HTTPS 页面拒绝不安全的远端语音地址。
- 更新服务工作线程缓存，只清理本站旧缓存；首次安装不再误报新版本。

## 运行与验证

需要 Node.js 22 或更新版本。首次安装：

```bash
npm ci
npm test
npm run check
npx wrangler deploy --dry-run
```

真实浏览器回归：

```bash
npx playwright install chromium
npm run test:browser
```

也可通过 `BROWSER_PATH=/绝对路径/chromium npm run test:browser` 指定已有浏览器。测试自行启动本地 Worker 路由与静态资源服务，覆盖 360、390、412、820、1440 像素宽度、全部练习入口、作答与学录同步、对话、离线加载、旧存档迁移及 Android 壳入口。结果与截图在 `output/playwright/`，不会提交依赖和临时输出。

## 验证边界

系统朗读是否可用取决于设备安装的中英文音色。云端 AI 和语音需要可用密钥或自建服务；自动测试使用模拟上游，未消耗用户的付费额度，也不代表用户外部服务在线。首次访问且从未成功缓存的网页不能凭空离线加载。

旧核心以已编译脚本交付。本次尽量以独立 V9 样式与脚本扩展，只有进度事件、启动、语音及共享词库等少量位置修改核心；后续重新构建核心时应保留这些连接点。
